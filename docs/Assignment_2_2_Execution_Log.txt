Design / rubric checklist:
1. Network socket stability:
   - TCP listener binds to localhost and accepts connections.
   - Client uses a connection timeout; sockets use read timeouts.
   - New client connections are handled in daemon worker threads.
2. Serialization and transport:
   - Typed messages are serialized as UTF-8 JSON.
   - Newline framing separates messages on a persistent TCP stream.
   - Every message carries protocol, UUID message ID, type, sender, timestamp, reply_to, and object payload.
3. Proactive remote message handling:
   - Agent-B acknowledges STATE_TRANSFER and reads active parameters.
   - Agent-B parses INSTRUCTION messages and autonomously evaluates task rules.
   - PING receives PONG; unknown instructions return a typed ERROR.
4. Thread safety:
   - A lock protects server log output; connection handlers own their socket streams.
   - This assignment builds on the previous ADSPA rules and thread-based work.
